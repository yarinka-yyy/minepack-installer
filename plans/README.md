# Планы реализации

Рабочий каталог Git-проекта — `app/`. Выполнять планы по одному. Статус `ACTIVE` означает, что план выбран для следующего запуска, но его реализация начинается только после команды пользователя «приступай» или равнозначной.

| План | Результат | Статус |
| --- | --- | --- |
| [001 — Основа установщика](001-foundation.md) | WPF-приложение устанавливает небольшой закреплённый тестовый Fabric-пакет в отдельный каталог; поддерживает проверку, восстановление и безопасное удаление | DONE |

После выполнения и проверки плана — один или несколько осмысленных коммитов в `app/` и push в `git@github.com:yarinka-yyy/minepack-installer.git` по уже данному пользователем поручению. Исполнитель плана не делает commit/push: сначала основной агент проверяет diff и результаты.

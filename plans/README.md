# Планы реализации

Рабочий каталог Git-проекта — `app/`. Выполнять планы по одному. Статус `ACTIVE` означает, что план выбран для следующего запуска, но его реализация начинается только после команды пользователя «приступай» или равнозначной.

| План | Результат | Статус |
| --- | --- | --- |
| [001 — Основа установщика](001-foundation.md) | WPF-приложение устанавливает небольшой закреплённый тестовый Fabric-пакет в отдельный каталог; поддерживает проверку, восстановление и безопасное удаление | DONE |
| [002 — Два языка и два README](002-localization-and-readmes.md) | Русский и английский интерфейс с выбором по языку Windows; понятные README на английском и русском с полным каталогом закреплённой сборки | DONE |
| [003 — Автоматический цикл Launcher и очистка артефактов](003-launcher-lifecycle-and-artifact-retention.md) | При установке MinePack закрывает официальный Launcher и открывает его после успеха; локальные артефакты старых тестовых сборок удалены с сохранением четырёх нужных копий | DONE |
| [004 — Vanilla 2 Plus с модами Macaw's](004-vanilla-2-plus-macaws.md) | Отдельный закреплённый релиз на основе Vanilla Plus с пятью строительными модами; выбор в установщике, сохранение прежнего instance и проверка совместимости в игре | DONE |

`ACTIVE` не означает разрешение на реализацию: нужен отдельный сигнал пользователя «приступай» или равнозначный. Исполнитель не делает commit/push; основной агент сначала проверяет diff и результаты. Публикация требует отдельного поручения.

План 002: build, smoke и publish прошли; визуальная приёмка WPF на RU/EN и GitHub preview остаются ручными проверками перед публикацией.

План 003: build, smoke и publish прошли; четыре нужные publish-копии сохранены, 12 проверенных старых каталогов удалены. После исправления неверной привязки имени файла профилей живой Store/Xbox Launcher пользователя был закрыт до установки и повторно открыт после неё. Отдельная установка 0.9.0 и профиль MinePack подтверждены; затем прежний `gameDir` MinePack восстановлен из резервной копии, три других профиля не изменились. Классический Win32 остаётся проверенным только smoke-тестами, поскольку на этой машине его нет. Предупреждение `NU1900` исчезло после восстановления из обычного Windows-сеанса; аудит NuGet не нашёл уязвимых пакетов.

План 004: код, Packwiz-архивы, build, smoke и временная установка с реальными загрузками/SHA-512 готовы. Проверка Fabric profile исправлена: два изменчивых поля времени исключены из закреплённого хеша JSON, остальные поля проверяются. Vanilla 2 Plus запущена через официальный Launcher; пять модов загружены, тестовый мир открыт и сохранён, пользователь проверил предметы и блоки всех пяти. Профиль MinePack возвращён на прежний instance, остальные три профиля не изменились; английский экран проверен вручную. В `latest.log` остались косметические предупреждения ресурсов Macaw's JAR и значков Mod Menu; детали в плане 004.

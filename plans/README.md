# Планы реализации

Рабочий каталог Git-проекта — `app/`. Выполнять планы по одному. Статус `ACTIVE` означает, что план выбран для следующего запуска, но его реализация начинается только после команды пользователя «приступай» или равнозначной.

| План | Результат | Статус |
| --- | --- | --- |
| [001 — Основа установщика](001-foundation.md) | WPF-приложение устанавливает небольшой закреплённый тестовый Fabric-пакет в отдельный каталог; поддерживает проверку, восстановление и безопасное удаление | DONE |
| [002 — Два языка и два README](002-localization-and-readmes.md) | Русский и английский интерфейс с выбором по языку Windows; понятные README на английском и русском с полным каталогом закреплённой сборки | DONE |

`ACTIVE` не означает разрешение на реализацию: нужен отдельный сигнал пользователя «приступай» или равнозначный. Исполнитель не делает commit/push; основной агент сначала проверяет diff и результаты. Публикация требует отдельного поручения.

План 002: build, smoke и publish прошли; визуальная приёмка WPF на RU/EN и GitHub preview остаются ручными проверками перед публикацией.
